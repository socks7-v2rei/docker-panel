# پنل اجرای داکر روی Vercel

این یه پروژه‌ی کوچیکه که خودش باید یه‌بار روی Vercel دیپلوی بشه. بعد از اون، یه صفحه‌ی وب بهت می‌ده که هر بار یه نام ایمیج داکر بدی، به‌صورت خودکار به‌عنوان یه Vercel Function دیپلویش می‌کنه.

## چطور کار می‌کنه؟

- صفحه‌ی اصلی (`index.html`) یه فرم داره
- وقتی دیپلوی می‌زنی، درخواست می‌ره به `api/deploy.js`
- اون فایل یه `Dockerfile.vercel` با محتوای `FROM <ایمیج تو>` می‌سازه و از طریق **Vercel REST API** یه دیپلوی جدید می‌سازه
- `api/status.js` هم وضعیت دیپلوی رو چک می‌کنه تا وقتی آماده بشه

## مرحله ۱: گرفتن توکن Vercel

برو به [vercel.com/account/tokens](https://vercel.com/account/tokens) و یه توکن جدید بساز. این توکن رو موقع استفاده از پنل وارد می‌کنی (فقط توی مرورگرت می‌مونه، جایی ذخیره نمی‌شه).

## مرحله ۲: دیپلوی خود این پنل روی Vercel

### روش ساده‌تر: با Vercel CLI

```bash
npm install -g vercel
cd docker-panel
vercel
```

سوالاتی که می‌پرسه رو با پیش‌فرض جواب بده (Other/No framework).

### یا از طریق گیت‌هاب

1. این پوشه رو به یه ریپوی گیت‌هاب پوش کن
2. توی [vercel.com/new](https://vercel.com/new) ریپو رو وصل کن
3. دیپلوی کن — نیازی به تنظیم خاصی نیست (Framework Preset: Other)

## مرحله ۳: استفاده از پنل

بعد از دیپلوی، آدرس پروژه‌ات رو باز کن (مثلاً `https://docker-panel-xxx.vercel.app`) و:

1. توکن Vercel رو بزن
2. اسم پروژه‌ای که می‌خوای ایمیجت توش اجرا بشه رو بزن (اگه وجود نداشته باشه خودکار ساخته می‌شه)
3. نام ایمیج داکر رو بزن — مثلاً:
   - `nginx:latest`
   - `redis:7`
   - `myusername/myapp:latest`
4. دکمه‌ی «دیپلوی کن» رو بزن

## نکات مهم

- ایمیج باید یه **سرور HTTP** باشه که روی پورت `$PORT` (پیش‌فرض 80) گوش می‌ده. کانتینرهایی مثل دیتابیس یا سرویس‌های بدون HTTP این‌جا کار نمی‌کنن (توضیحش قبلاً داده شد: مدل Vercel Function استیت‌لسه و فقط HTTP رو سرو می‌کنه).
- اگه ایمیجت private هست (نه روی رجیستری عمومی)، این نسخه ساده جوابگو نیست و باید احراز هویت رجیستری رو هم اضافه کنیم — بگو تا اضافه‌ش کنم.
- اگه پروژه‌ات زیر یه تیمه، `Team ID` رو هم پر کن (از تنظیمات تیم توی Vercel قابل مشاهده‌ست).
